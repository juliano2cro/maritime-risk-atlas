# Interface Maritime Risk Atlas

Application React Router du monorepo. Installer les dépendances depuis la racine avec `npm ci`, puis lancer `npm run dev:web`.

Copier `.env.example` en `.env` et renseigner l’URL du style de carte. `VITE_API_URL` désigne l’API Express. Voir le README racine pour le lancement complet et les vérifications.

Le Dockerfile hérité du prototype doit encore être adapté au verrou npm racine ; il n’est pas validé à cette étape.
